Welcome to my Data Science Internship repository! This workspace contains all the completed tasks, exploratory data analyses, and machine learning models developed during my internship program.


## 🛠️ Tech Stack & Libraries
* **Programming Language:** Python 3.x
* **Data Manipulation & Analysis:** `pandas`, `numpy`
* **Machine Learning:** `scikit-learn` (Linear Regression, K-Means, Random Forest, SVC, SGD, Logistic Regression)
* **Data Visualization:** `matplotlib`, `seaborn`
* **Development Environment:** Jupyter Notebook, VS Code

---

## 📂 Repository Structure & Projects

### 📊 Level 1: Core Data Analysis & ML
1. **Task 1: Retail Sales EDA (`Retail_Sales_EDA.ipynb`)**
   * Performed Exploratory Data Analysis on retail sales data.
   * Inspected data quality, summary statistics, temporal trends, and product category performance.
   * Generated actionable business insights and visualizations.

2. **Task 2: Customer Segmentation (`Customer_Segmentation.ipynb`)**
   * Applied unsupervised machine learning (**K-Means Clustering**).
   * Engineered **RFM (Recency, Frequency, Monetary)** behavioral features.
   * Determined optimal cluster count using the Elbow Method and profiled customer segments.

3. **Task 3: Car Price Prediction (`Car_Price_Prediction.ipynb`)**
   * Built a regression model to predict vehicle resale values.
   * Handled data preprocessing, train-test splits, and evaluated performance using MAE, RMSE, and $R^2$ scores.

---

### 🤖 Level 2: Advanced Machine Learning & Predictive Modeling
1. **Task 1: House Price Prediction (`House_Price_Prediction.ipynb`)**
   * Developed an end-to-end regression pipeline for real estate valuation.
   * Handled data cleaning, outlier detection, and one-hot encoding.
   * Evaluated model residuals and compared performance against regularized models (Ridge & Lasso).

2. **Task 2: Wine Quality Prediction (`Wine_Quality_Prediction.ipynb`)**
   * Built and compared multiple multi-class and binary classifiers (**Random Forest, SGD Classifier, and SVC**).
   * Handled class distribution analysis, feature binned classification, and evaluated models using accuracy, confusion matrices, and feature importance charts.

3. **Task 3: Fraud Detection (`Fraud_Detection.ipynb`)**
   * Built a fraud detection classification pipeline for heavily imbalanced financial transactions ($\approx 1\%$ fraud rate).
   * Addressed class imbalance using **SMOTE** oversampling and stratified splitting.
   * Evaluated models prioritizing **Precision, Recall, F1-Score, and AUC-ROC curves**, alongside scalability discussions for high-throughput systems.
